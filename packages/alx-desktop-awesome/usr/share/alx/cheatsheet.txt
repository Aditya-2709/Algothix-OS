========================================================================
           ALGOTHIX OS (ALX) LITE — AWESOME WM KEYBINDINGS
========================================================================

  WINDOWS & APPS
    Super + Enter          Open terminal (urxvt)
    Super + d              App launcher (rofi icon grid)
    Super + a              Toggle ALX Start Menu (apps & power)
    Super + e              File manager (pcmanfm)
    Super + Shift + q      Close focused window
    Super + ?              Show this keybinding cheat-sheet

  ALX ASSISTANT (OPTIONAL — install via 'alx-setup assistant')
    Super + i              Launch / talk to ALX Assistant
    Super + Shift + i      ALX Assistant text-prompt mode
    Super + Shift + Esc    PANIC STOP (kills assistant immediately)
    Config hotkeys:        ~/.config/alx-assistant/hotkeys.env

  NAVIGATION & LAYOUT
    Super + h/j/k/l        Focus left / down / up / right (or Arrows)
    Super + Shift + h/j/k/l Swap focused window
    Super + Space / t      Cycle tiling layouts (tile, bottom, max, float)
    Super + Ctrl + h / l   Shrink / grow master column width
    Super + f              Toggle fullscreen
    Super + Shift + Space  Toggle floating window

  TAGS (WORKSPACES)
    Super + 1..5           Switch tag (1:term, 2:code, 3:web, 4:ops, 5:misc)
    Super + Shift + 1..5   Move focused window to tag

  SESSION
    Super + Shift + r      Reload Awesome WM
    Super + Shift + e      Quit Awesome WM (return to SDDM)

  TERMINAL & ALX TOOLS
    tmux prefix: Ctrl+a    (| split vertical, - split horizontal)
    nvim / lazygit         Minimal Neovim + Terminal Git UI
    alx-setup list         Install language stacks, localsend, kdeconnect, assistant
    alx-link status        Tailscale/WireGuard, SSH, Syncthing, clip, notify

  Press 'q' to close this window.
========================================================================
